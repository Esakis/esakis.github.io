# Łukasz Sroka Tech

![Łukasz Sroka Tech - Angular i .NET](https://esakis.github.io/og-image.png)

Portfolio firmy tworzącej dedykowane aplikacje webowe dla firm w Angular i .NET.

**Strona:** [esakis.github.io](https://esakis.github.io/)

## Specjalizacja

- Dedykowane aplikacje biznesowe: Angular, .NET, baza danych i wdrożenie.
- Rozwój i modernizacja istniejących systemów.
- Integracje API, KSeF, automatyzacje oraz generowanie dokumentów.

## Technologie

- Angular i TypeScript
- .NET / C# oraz ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL i SQL Server
- Docker, Azure i Python

## Uruchomienie lokalne

Wymagany jest Node.js 20.19 lub nowszy.

```bash
npm ci
npm start
```

Aplikacja jest dostępna pod adresem `http://localhost:4200/`.

## Build i wdrożenie

```bash
npm run build
```

Build wykonuje statyczny prerender Angulara. GitHub Actions publikuje artefakt z `dist/portfolio/browser` na GitHub Pages.
